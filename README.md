# XeneonTube download

Download **XeneonTube-Windows.zip** from this branch using GitHub's **Download raw file** button. Extract the ZIP on your Windows PC and follow the included README.md.

The bundle contains one XeneonTube.icuewidget with Automatic, Compact, Medium, and Wide width options, plus the local companion application and source.

Requires Node.js 24.5+, iCUE 5.52+ with Widget API 1.9.0 support, and your own free YouTube Data API v3 key. Run Start-XeneonTube.cmd on the Windows PC connected to the XENEON EDGE, configure the key locally, then import dist/XeneonTube.icuewidget in iCUE. No API key is included.

Automated service/browser-simulation checks and CLI packaging passed. Actual Windows/iCUE playback, audio, and touch remain unverified.
